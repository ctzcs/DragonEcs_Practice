## 简单回合制游戏
- 回合制游戏可能不适合ECS，因为这个工程只是一个实验
- 向Ecs发出请求
  - View
  - UI
- 响应ECS数据变化模块
  - View这部分可以直接位于Ecs内部

- 游戏逻辑
  - 玩家点击进入游戏
  - 帧开始
    - 地图生成
      - 回合开始
      - 玩家行动
        - 游戏是否结束
        - 等待玩家操作
      - AI行动
      - 场景变化
      - 回合结束

## 注意点
- 让事件处理发生在事件发出之后
- 事件处理完成，删除事件
  - 唯一担心的事件，会不会有多个系统想监听同一个事件的， 这种情况发生的时候，是不是应该让最后一个系统来清理事件
- 递归事件怎么办
- UI如何接收事件
  - 动画事件不应该延迟处理，
